# Future Music Visualizer

A futuristic Android music player prototype designed around:
- background audio playback
- reactive visualizer driven by live audio levels
- 12-band equalizer-inspired slider controls
- multiple neon presets and sound effects
- modern dark UI with a synthwave/futuristic look

## Included features
- Background synth engine running in a foreground service
- Real-time visualizer bars
- Preset-driven equalizer profiles
- Dynamic glow and pulse effects
- Material 3 inspired interface

## Android project status
This repository is set up as an Android app project. Open it in Android Studio and let Gradle sync the project.

## Main package
`com.futuremusic.visualizer`

## Run
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Run the `app` module on an Android device or emulator.

## Notes
This is a prototype music player with a generated synth-style engine rather than a pre-bundled commercial audio file, so it runs without additional assets while still giving a strong futuristic music-player experience.
